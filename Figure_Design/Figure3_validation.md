# Figure 3 — Validation and Translation

- Purpose：验证模型、机制和治疗策略的稳健性与转化潜力。
- Key message：核心发现可跨供体、批次或模型复现，并具有安全性依据。

| Panel | Proposed content | Required data |
|---|---|---|
| A | Independent validation | 独立批次/供体 |
| B | Dose or time response | 剂量与时间曲线 |
| C | Functional efficacy | 创面闭合、菌负荷或屏障 |
| D | Safety | 细胞毒性、炎症、组织学 |
| E | Translational summary | 临床场景与决策框架 |
